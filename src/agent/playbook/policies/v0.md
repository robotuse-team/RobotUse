# RobotUse agent playbook v0

Use this playbook as decision guidance. Current observations, tool schemas, measured geometry, feasibility results and the native task verifier remain authoritative.

## common

Use only current references and measured connector-base geometry. Treat commanded motion success as distinct from object retention and task success. Never infer hidden geometry or release an object without fresh evidence and an explicit Prime decision.

## prime

`delegate_grasp.grasp_feedback` reports the previous Grasp sub-agent's selected candidate and public tool feedback. It is a historical selection, not a measured executed pose or proof of object retention. On a retry, include your observed failure (or the reported tool failure) in the next `delegate_grasp` instruction and ask Grasp to reconsider its choice using that feedback. Do not invent a failure when the outcome is uncertain.

For every transport pick, supervise an outgoing contact-center height at least 0.20 m above the selected grasp height. After the lift, inspect the fresh observation. If more clearance is useful, request additional upward `move_vertical` motion before transport or placement. This is Agent decision guidance rather than an automatic numeric clamp.

## point

Select the requested target, destination or observation waypoint from current calibrated images. Return measured references only; do not invent base-frame coordinates or reuse stale references after motion.

## grasp

When supplied, `previous_grasp_feedback` contains the previous Grasp sub-agent's selected candidate and public tool feedback. Use it together with Prime's current instruction describing the observed failure to reconsider your choice. It may concern a different target; compare the instructions. Historical references cannot be executed or reused as current candidates. You may choose another source or angle; repeating a choice requires a reason based on current evidence. Command completion alone does not establish a successful grasp.

For a transport pick, choose `transit.post` so its resolved contact-center Z is at least 0.20 m above the selected grasp Z. The incoming (`transit.pre`) and outgoing (`transit.post`) heights may differ. Use current geometry to choose the height, and report failure when no offered pose and height are feasible.

## place

Choose placement XY, final height and transit height explicitly from current destination evidence. Keep the gripper closed through placement motion; Prime decides whether and when to release after reviewing fresh evidence.

## refiner

Review the selected grasp pose without silently changing its transit heights. Preserve top-down approach for mean or median grasps by allowing yaw only; use bounded full rotation adjustment only for Contact-GraspNet poses.
